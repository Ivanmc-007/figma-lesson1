# 🏗️ Спецификация компонентов и раскладки (Components & Layout)

Документ описывает логику построения переиспользуемых элементов интерфейса и применение инструментов автоматической раскладки (Auto Layout) в Figma.

## 1. Разбор компонента «Кнопка» (Button)
В макете создан интерактивный мастер-компонент кнопки, имеющий два состояния (Variants).

*   **Структура компонента:** Кнопка собрана на основе контейнера Auto Layout, что позволяет ей автоматически адаптироваться под длину текста. Внутри находятся текстовый слой и иконка стрелки (опционально).
*   **Состояния (Variants):**
    1.  `State: Default` — базовый вид кнопки со стандартным акцентным фоном.
    2.  `State: Hover` — состояние наведения. Настроен переход (Smart Animate, Dissolve, 300ms) для демонстрации интерактивности в режиме презентации (Prototype).
*   **Использование:** На страницах макета используются исключительно экземпляры (Instances) данного компонента, что гарантирует абсолютное единообразие UI.

## 2. Применение Auto Layout и связь с CSS Flexbox
Инструмент Auto Layout применен ко всем ключевым динамическим блокам макета, полностью повторяя поведение модели **CSS Flexbox**:

*   **Header (Шапка сайта):**
    *   *Настройки:* `Direction: Horizontal` (аналог `flex-direction: row`), `Justify Content: Space Between` (логотип прижат влево, контакты и CTA-кнопка — вправо).
    *   *Отступы:* Внутренние паддинги `Padding: XXpx XXpx`.
*   **Карточки секции «Педагоги»:**
    *   *Настройки:* Каждая карточка — это вертикальный Auto Layout (`Direction: Vertical` / `flex-direction: column`), где последовательно размещены фото, имя педагога и его направление.
    *   *Расстояние:* Параметр `Gap: XXpx` (аналог CSS-свойства `gap`) задает фиксированное расстояние между элементами внутри карточки.
*   **Ряд карточек (Секции Педагоги / Направления):**
    *   Общие контейнеры карточек выстроены горизонтально со значением `Gap: XXpx`.
