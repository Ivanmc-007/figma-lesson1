## 📂 Структура файлов в командной папке

Все материалы нашей команды изолированы и находятся строго внутри нашей директории:
* `exports/` — папка с экспортированными графическими файлами макета (PNG/WebP).
  * `desktop.png` — экспорт полной десктопной версии (1440px).
  * `mobile.png` — экспорт мобильной версии (390px).
* `design-system.md` — задокументированные цветовые токены (HEX), шрифты, стили типографики и описание созданных компонентов.
* `components.md` — подробный разбор структуры интерактивной кнопки, вариантов (Variants) и применения Auto Layout.
* `handoff.md` — спецификация для разработчиков: иерархия заголовков, alt-тексты для изображений и результаты теста контрастности WebAIM.
