## 🚀 Порядок выполнения и сдачи работы

1. **Форк и ветвление:** Тим-лид делает форк этого репозитория и создает рабочую ветку `homework-figma-1-team`.
2. **Изоляция:** Все коммиты, файлы документации (`design-system.md`, `components.md`, `handoff.md`) и графические экспорты вносятся строго внутрь папки вашей команды. Изменение файлов чужой команды или папки `.github/` запрещено.
3. **Авторы коммитов:** Каждый участник команды должен авторизоваться под своим аккаунтом GitHub и лично сделать как минимум один коммит в файлы своей папки.
4. **Pull Request:** По завершении работы тим-лид создает один Pull Request из ветки форка в ветку `main` основного репозитория. В описании PR заполняется командный шаблон.
