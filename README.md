## 📂 Структура файлов в командной папке

Все материалы нашей команды изолированы и находятся строго внутри нашей директории:
* `exports/` — папка с экспортированными графическими файлами макета (PNG/WebP).
  * `desktop.png` — экспорт полной десктопной версии (1440px) *(JUNIOR / PRO)*.
  * `mobile.png` — экспорт мобильной версии (390px) *(JUNIOR / PRO)*.
  * `tablet.png` — экспорт планшетной версии (768px) *(Только для PRO)*.
  * `stress-test-before.png` — скриншот гибкого блока до наполнения текстом *(Только для PRO)*.
  * `stress-test-after.png` — скриншот гибкого блока после вставки ~100 слов *(Только для PRO)*.
* `design-system.md` — задокументированные цветовые токены (HEX), шрифты, стили типографики и описание созданных компонентов.
* `components.md` — подробный разбор структуры интерактивной кнопки, вариантов (Variants) и применения Auto Layout.
* `handoff.md` — спецификация для разработчиков: иерархия заголовков, alt-тексты для изображений и результаты теста контрастности WebAIM.

## 📅 Краткое техническое задание и чеклист реализации

### 🔵 Для уровня JUNIOR (Лендинг танцевальной студии)
- [ ] **Design System:** Зафиксировано не менее 3 цветовых стилей и 4 текстовых стилей. Создан мастер-компонент кнопки `Button/Default` с настроенным состоянием `Hover`.
- [ ] **Desktop (1440px):** Собраны секции Header (на Auto Layout), Hero, направления, стоимость, педагоги и Footer.
- [ ] **Mobile (390px):** Реализована адаптивная адаптация первого экрана (Hero-секция) и навигационной шапки.
- [ ] **Прототипирование:** Настроено как минимум 2 интерактивных перехода между элементами макета.

### 🔴 Для уровня PRO (Лендинг тренажерного зала в Минске)
- [ ] **Design System:** Полная палитра (4+ цвета), 6+ текстовых стилей, компонент кнопки с 3 вариантами (`Default`, `Hover`, `Disabled`) + минимум 1 дополнительный сложный компонент (например, карточка).
- [ ] **Три фрейма адаптива:** Полностью отрисованы и заполнены макеты Desktop (1440px), Tablet (768px) и Mobile (390px).
- [ ] **Контент Минска:** Уникальные русскоязычные тексты, условные белорусские номера телефонов (`+375 XX XXX-XX-XX`), реальный адрес в Минске и карта (на базе OpenStreetMap с указанием атрибуции).
- [ ] **Адаптивный стресс-тест:** Проведена проверка текстовых контейнеров на переполнение длинным текстом (~100 слов), результаты зафиксированы скриншотами.
- [ ] **Прототипирование:** Настроено не менее 3 интерактивных переходов (включая навигацию в шапке и переходы к формам).
